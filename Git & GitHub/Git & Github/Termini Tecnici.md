

- Directory:
  Termine tecnico per le folder, usato nei sistemi operativi e nei file system.

  ![[Path to understand directory vs folder.png]]
  Come possiamo vedere da questa immagine, esattamente come nella [[Binary Tree Data Structure|binary tree data structure]] ci sono termini come *root* e *Parent directory*. Andando ad analizzare questa immagine:   ^b76863
  1. **Root:** 
     è la directory principale (Es: *This PC* ), da cui derivano tutte le altre directory. Questa directory è un astrazione nell'interfaccia grafica di Windows che mostra tutte le unità di memoria disponibili(dischi locali, dispositivi USB, unità di rete, ecc.)
  2. **Parent Directory:**
     è la directory che contiene  altre directory o file. 
     In questo caso *Local Disk* è la parent directory di windows. 
   3.  **Child Directory (Directory figlio)**: 
      è una directory contenuta all'interno di un'altra directory. 
      In questo caso, _Windows_ è una child directory di _Local Disk (C:)_.
  4. **Folder :**
     _Font_ è indicato come _Folder_, per evidenziare che nei sistemi Windows il concetto di _directory_ è rappresentato graficamente come una cartella (folder).
   
- [[#^folder|Folder]] :
   Temine user-friendly, usato nell'interfaccia grafica di Windows e MacOS per rappresentare una directory.  
   
> [!faq] Quindi quali sono le differenze tra directory e folder?
> Nessuna, è solo terminologica: ==una _folder_ può contenere altre _folder_, proprio come una _directory_ può contenere altre _directory_.==

- Terminal o Command Line(Linea di comando) → Interface for Text Commands(Interafaccia per i comandi di testo):  
    in parole povere è un'applicazione che viene eseguita sul tuo computer che è semplicemente un'interfaccia in cui si può digitare i comandi di testo. In pratica si può navigare tra file e cartelle, creare file, modificare ed aggiornare quello che vuoi, installare ed eseguire programmi, etc.
- CLI → Command Line Interface (Interfaccia della linea di comando):  
    è l'interfaccia delle riga di comando. Molti programmi che installi, in quanto programmmatore ti chiederanno di interagire tramite comandi di testo nella riga di comando; in pratica digiti il testo e premi invio invece di fare doppio clik sull'icona di una cartella sul desktop. Quindi bisogna pensarlo come un altro modo di eseguire un programma
- CD → Change Directory:  
    In parole povere è un commando che ti permette di spostare tra le directory sia principali che non, una volta dato questo comando devi dare anche le indicazioni per raggiungere qualsiasi directory del tuo sistema.
- Code Editor → Word Processor for Writing Code:  
    è un editor di codice (es: Visual studio Code)
- Repository → Progetto o cartella/posto dove il progetto è conservato:  
    la parola repository ha molteplici significati, nel mondo della programmazione di solito viene usata per indicare una repository git.
- Github:  
    è un sito web in cui ospiti tutti i tuoi repository git.  
    Il fatto che sia online ti permette di lavorare in gruppo con altre persone e organizzare i tuoi progetti in un portfolio da mostrare ai potenziali datori di lavoro.
- Git:  
    è lo strumento che tiene traccia delle modifiche apportate al tuo codice nel tempo
